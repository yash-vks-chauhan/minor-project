Analysis specification fixed before running the revised models
============================================================

This is a documented exploratory reanalysis, not a preregistration or a new independent study. Earlier manuscript results were already known. All changes in sources and definitions will be disclosed.

Use every Indian state with a nonmissing value across the seven analytical input tables. Union Territories are excluded to keep the administrative comparison consistent. Missing e-waste entries and absent states are missing, never zero. Use the full publicly available CPCB table rather than the incomplete legacy spreadsheet.

Sources: TRAI total tele-density on 30 June 2024 via the parliamentary reply published by PIB; rounded state UPI transactions/person for FY2024-25 transcribed from the Dataful article/map; current-price per-capita NSDP for FY2023-24 from Economic Survey 2025-26 Table 1.11A (vintage 1 August 2025); NITI SDG India Index 2023-24 composite score; CPCB e-waste collected and processed FY2021-22 via PIB; MoHFW Technical Group on Population Projections 2020 report, Tables 11 and 13, for projected population and urban share as of 1 July 2021. Archived mirror retrieval of the government population document will be disclosed. Projections are not a 2021 census count. Sources have different reference periods; the analysis is ecological and associational.

Retain a descriptive index for continuity, with actual min-max normalization to 0-100. Remove NSDP from both component scores, then renormalize the legacy non-income weights: DAS = (4*Tnorm + 3*UPInorm)/7; circularity-related proxy = (7*EWnorm + 8*SDGnorm)/15; descriptive DCI = DAS*proxy/100. The overall SDG composite is a broad development measure, not a direct CE behavior measure. NSDP will only be an explanatory covariate. The index is sample-relative; predictive validation will not use a target normalized with full-sample extrema.

Report Pearson and Spearman association for DAS/proxy, a two-sided 19,999-permutation test, 10,000 state bootstrap resamples, and regression with log NSDP using HC3 standard errors and t-based inference. Sensitivities: equal component weights, removal of Haryana, every other one-state deletion, use of e-waste alone, and log-transformed e-waste. Report small-sample and post-selection limits. Do not retain mediation or a tele-density threshold as established evidence.

Predictive targets are the directly measured SDG composite and log(1 + e-waste tonnes per million people), analyzed separately. Predictors: digital-only (tele-density and rounded UPI/person), and augmented (digital predictors plus log NSDP, projected urban share, and log projected population). Compare Ridge, ElasticNet, Random Forest, and XGBoost with an outer leave-one-state-out evaluation and inner shuffled four-fold tuning (seed 20261026), using negative mean squared error. All preprocessing is fitted inside the relevant training fold. No target transforms dependent on other states enter this validation. Score pooled outer predictions with R-squared, RMSE, and MAE, alongside an outer-training-mean baseline. Store finite inner scores, exact splits, parameters, and outer predictions. Negative scores are retained. The best model is an exploratory comparison, not a confirmed deployment choice.

Use small explicit grids and single-thread estimators: Ridge alpha [0.1,1,10,100]; ElasticNet alpha [0.01,0.1,1] and l1_ratio [0.2,0.5,0.8]; RF 200 trees, depth [2,3], leaf [2,4]; XGBoost n_estimators [100,200], depth [1,2], learning_rate [0.05,0.1], min_child_weight 3, reg_alpha 1, reg_lambda 2, subsample 0.8, colsample_bytree 0.8. A practical identity check will ensure every observation is held out exactly once and no held-out state enters its tuning splits.

For interpretation, compute held-out SHAP values for XGBoost using each outer model. Treat them as model explanations, not causal effects. Explain the displayed model and target explicitly. No model will be selected because it produces a desired result.
