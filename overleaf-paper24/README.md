Use this folder as the Overleaf project instead of uploading the full repository.

Files included:
- `main.tex`
- `figures/fig2_digital_vs_ce_scatter.jpg`
- `figures/fig3_dci_ranking.jpg`
- `figures/fig17_shap_beeswarm.jpg`
- `fonts/` (empty placeholder folder)

Overleaf setup:
1. Create a new Overleaf project.
2. Upload everything inside this folder.
3. Set the compiler to `XeLaTeX`.
4. If you want Gill Sans, upload these font files into `fonts/`:
   - `GillSans.ttf`
   - `GillSans-Bold.ttf`
   - `GillSans-Italic.ttf`
   - `GillSans-BoldItalic.ttf`

Notes:
- If those Gill Sans files are not uploaded, `main.tex` falls back to `Helvetica`.
- This reduced project is much smaller and is intended to avoid Overleaf free-plan compile timeouts caused by uploading the whole repository.
